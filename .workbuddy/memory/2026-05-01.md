# 2026-05-01 工作日志

## 排查推送不触发问题
- 发现 CF cron 在某些边缘节点（如美国）执行时被 Binance 返回 HTTP 451 地区限制
- 手动 POST /api/trigger 走香港节点（HKG），没问题
- 发现 zhuzhu 的 cookie 过期导致 UNAUTHORIZED（手动触发时暴露）
- 添加了 `/api/cron-status` 和 `/api/debug` 调试接口
- cron 现在通过 fetch 自己的 /api/trigger 执行（而非直接调 Binance API），并记录边缘节点 colo

## 新增 auto-login.cjs
- 使用 puppeteer-core 弹出 Chrome 浏览器
- 打开 Binance 登录页，用户扫码登录后自动提取 cookie 和 CSRF token
- 自动写入 .dev.vars
- 命令：`node auto-login.cjs [用户编号]`
